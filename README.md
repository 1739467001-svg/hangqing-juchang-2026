# 行情剧场 · 交易人格试炼（THE MARKET THEATRE）

> 2026 苏客松 · 赞助商赛道（PandaAI）参赛作品 —— 代码与运行说明

## 一句话介绍

一款 4–6 分钟、手机可玩的 H5 游戏：把 **8–12 段真实历史行情**改编成限时决策剧场，玩家用**行为**（而非问卷）照见自己的交易人格，并获得千人千面的「下一步」——完整覆盖赛题四环闭环：**互动 → 画像 → 推荐 → 下一步**。

## 运行方式（零依赖）

- **方式一（最简）**：双击 `app/index.html` 即可玩。单文件产物，无任何第三方运行时依赖，**离线可玩**（行情已预烘焙内联）。
- **方式二（展位模式）**：
  ```bash
  python3 app/server.py 8000
  ```
  - 玩家入口：`http://<本机IP>:8000/`
  - 人格大屏：`http://<本机IP>:8000/screen.html`（实时人格分布 + **今日收益榜 TOP5**，投到电视/投影）
  - 展位海报：`http://<本机IP>:8000/poster.html`（截图送打印）
- **评委快速模式**：访问 `/?fast`——剧情 0.9 秒、倒计时 8 秒，展位快速演示用。
- 剧本切换：开场页「剧本」按钮可切换 **8 幕标准版 / 12 幕完整版**。
- **发布公网链接**：`bash 提交材料/deploy_github_pages.sh`（一键 GitHub Pages；发布属对外动作，需队内确认后执行）。

## 引擎方法（可解释、可复现、无 ML 库）

1. 玩家在每个关卡的选择对各行为维度产生增量（±1~3）；
2. 六维画像 = 增量求和 → max-abs 归一化；
3. 分类 = 最近质心（4 种人格原型），光谱占比 = softmax(−2.2·距离)；
4. **理论验证**（`persona_sim` 系列）：4 原型 × softmax 行为模型模拟玩家，12 关分类准确率 **99.4%**，冠军 8 关 **100%**（穷举全部 C(12,8)=495 种组合）；混合型玩家稳健性测验驱动了「人格光谱」而非单标签的设计。
